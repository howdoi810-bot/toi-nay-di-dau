# Tối Nay Đi Đâu? — Xé Túi Mù Chốt Kèo Đi Chơi 🎁🌙

Ứng dụng web giải quyết câu hỏi đau đầu mỗi tối của giới trẻ, dân văn phòng và các cặp đôi Việt Nam: **"Tối nay đi đâu? / Ăn xong đi đâu giờ?"** — kết hợp cùng trào lưu **Xé Túi Mù (Blind Bag / Pop Mart)** cực cuốn.

## ✨ Tính năng nổi bật

- **Cơ chế Xé Túi Mù (Blind Bag) xúc giác**:
  - **Lắc thử túi**: Nghe tiếng bao giấy bạc sột soạt (tổng hợp bằng Web Audio API) kèm lời "spoil" hài hước.
  - **Kéo ngang đường răng cưa** hoặc bấm **Xé Túi Mù Ngay** để khui thẻ kèo đi chơi.
  - **2 Chế độ khui**: **Xé 1 Túi Lẻ (Kèo Nhanh)** và **Combo 3 Túi: Kèo Nguyên Đêm (Tăng 1 Ấm Bụng + Tăng 2 Đi Chill + Thẻ Luật Ngầm)**.
- **Check Nguyện Vọng (Lấy cảm hứng từ Livestream Túi Mù TikTok)**:
  - Chọn nguyện vọng trước khi xé (*Chill Chữa Lành, Quẩy & Náo Nhiệt, Lãng Mạn Tình Cảm, Độc Lạ Tâm Linh*).
  - Khi xé trúng thẻ khớp Nguyện Vọng: nổ pháo hoa **TRÚNG NGUYỆN VỌNG!** và tặng kèm **+1 Thẻ Thưởng Secret/Cực Phẩm**.
- **5 Cấp độ hiếm Sưu Tập (Art-Toy Rarity)**:
  - `BASIC` (Thường - 48%) • `RARE` (Hiếm - 30%) • `SUPER RARE` (Cực Phẩm - 15%) • `SECRET` (Bí Ẩn - 6%) • `MEGA SECRET 1:144` (Thần Thoại - 1%).
- **4 Giao diện (Theme) đậm chất đêm Việt Nam**:
  - 🧸 *Tiệm Túi Mù* (Pop-Art Neon)
  - 🛵 *Hẻm Đêm Sài Gòn* (Đèn Neon & Ghế Nhựa Đỏ)
  - 🔮 *Tiệm Tarot Đêm* (Tín Hiệu Vũ Trụ)
  - 🌸 *Duyên Đêm City-Pop* (Trạm Hẹn Hò 80s FM)
- **Xuất Ảnh "Thẻ Chốt Kèo" & Mở Google Maps 1 Chạm**:
  - Gợi ý tọa độ theo từng thành phố (*Sài Gòn, Hà Nội, Đà Nẵng, Toàn quốc*).
  - Tạo ảnh PNG **Bản Cam Kết Chốt Kèo** kèm **Luật Ngầm chống bùng kèo** để gửi ngay vào Zalo / Messenger / Instagram Story.

## 🚀 Chạy trên máy (Local Development)

```bash
npm install
npm run dev
```

Mở `http://127.0.0.1:5173` trên trình duyệt. Không cần đăng nhập, không cần cấu hình `.env` hay dịch vụ đám mây.
